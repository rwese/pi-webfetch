# Bug Reports

This directory holds individual bug reports for the `@rwese/pi-webfetch` package.
Each report is a self-contained plan: a single ID, a single root cause, a
single fix. Reports are sorted by ID, which is sortable lexicographically ==
chronologically.

## ID format

IDs are generated by the `next-id` tool with the `BUG-` prefix. The canonical
15-char tail (`YYYY-MM-DD-TTTTTTTT`) is what makes the ID unique; the prefix
is for human grouping. See `~/.agents/references/task-id-naming.md`.

## Conventions

- One report per ID. If a fix uncovers a second root cause, open a new report
  and cross-link from the original.
- Each report follows the plan template in
  `~/.agents/references/plan-template.md` plus the frontmatter fields
  `severity`, `type`, `component`, `reported`, `tested_against`, and
  `test_matrix`.
- Each report's `TODO` section is the contract for "done". Check off the
  boxes as the fix lands.
- Each report's `Acceptance Criteria` is the contract for the test matrix
  call. The test matrix in `.agents/references/webfetch-testing.md` is
  the regression suite.
